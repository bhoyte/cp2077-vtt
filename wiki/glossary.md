# Glossary

- **Seat** — one of four crew characters: Solo, Netrunner, Tech, Face. **Squad** — the viewers piloting a seat.
- **Handler / Fixer** — the streamer's diegetic persona (off-camera voice).
- **Window** — the vote period for one seat's slot. **Grace (L)** — extra server-side seconds covering broadcast delay.
- **Lock-in** — early window close on clear consensus.
- **Slot** — one entry in the initiative order (party or enemy).
- **Beat** — a short timeline of stage ops (cuts, poses, FX, kills) that renders one outcome. **Beat template** — authored beat with variants (miss/hit/crit/kill).
- **StageSpec** — the declarative desired state of the set; the reconciler makes the game match it.
- **Node** — a tagged point in a scene (cover, console, vantage). **Affordance** — a node tag that enables actions.
- **Player park** — where invisible V waits so the world streams around the set.
- **FakeStage / tactical feed** — the 2D stand-in renderer; dev harness and on-air failover.
- **Ledger** — the event-sourced SQLite store.
- **Commit / reveal** — publish SHA-256(seed) at start, reveal the seed at the end; proves dice weren't fudged.
- **L0 / L1** — deterministic vote parsing / Jev classification of free text.
- **Open seat** — a seat with too few squad members, opened to the whole crew.
- **Temperament** — a character's default behaviour when nobody votes.
- **Flatlining** — 0 HP; death saves each turn until stabilized or dead.
- **Spike / Glitch** — exploding natural 10 / natural 1 on a check.
- **Gate (G1–G4)** — roadmap checkpoints: First Light, Ghost Cabinet, Vertical Slice, Launch.
