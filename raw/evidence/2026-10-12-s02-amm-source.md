## Pose SQL

`workspots` columns: `anim_id`, `anim_name`, `anim_rig`, `anim_comp`, `anim_ent`, `anim_fav`, `anim_cat`.
Every workspot row uses `anim_ent = base\amm_workspots\entity\workspot_anim.ent`.
`anim_comp` is `amm_workspot_base` (39236) or `amm_workspot_custom_base` (4529). `anim_cat` is NULL on all 43765 rows (no collab poses in this DB).

`photomode_poses` columns: `pose_name`, `ignore`. 142 rows. Keyword hits there: crouch 2, hand 5, talk 1, lean 5, sit 1. No aim, typing, kneel, dead, or bar.

Queries (Python sqlite3), then the rows kept as candidates:

```sql
SELECT anim_name, anim_rig, anim_comp
FROM workspots
WHERE anim_name = ?
ORDER BY anim_rig;

SELECT pose_name FROM photomode_poses
WHERE pose_name LIKE '%aim%' OR pose_name LIKE '%crouch%'
   OR pose_name LIKE '%hand%' OR pose_name LIKE '%talk%'
   OR pose_name LIKE '%lean%' OR pose_name LIKE '%sit%';
```
